## 📖 Temario de las Clases
1. **Clase 1:** Introducción a Sistemas Distribuidos.
2. **Clase 2:** Multitasking y Comunicaciones.
3. **Clase 3:** Paralelización, Multiprocesadores y Nombres.
4. **Clase 4:** Interfaces y Protocolos.
5. **Clase 5:** Mensajes, Grupos, Middlewares y MOMs (RabbitMQ).
6. **Clase 6:** Práctica de Diseño Multicomputing.
7. **Clase 7:** Patrones de Comunicación y ZeroMQ.
8. **Clase 9:** Arquitecturas Distribuidas Simples.
9. **Clase 10:** Distribución y Coordinación de Procesos.
10. **Clase 11:** Sistemas Elásticos y de Alta Disponibilidad.
11. **Clase 13:** Data Intensive Applications (Aplicaciones de Datos Intensivos).
12. **Clase 15:** Diseño de Arquitecturas de Gran Escala.
13. **Clase 16:** Arquitecturas Orientadas a Servicios (SOA) y Cloud.
14. **Clase 17:** Tolerancia a Fallos.
15. **Clase 19:** Algoritmos de Consenso (Raft, Paxos, etc.).
16. **Clase 20:** Tiempo, Relojes, Sincronismo, Orden y Cortes de Estado.
17. **Clase 21:** Introducción a Sistemas de Tiempo Real.
